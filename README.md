# Verse Vault

A scripture memorization app built with .NET and Blazor.

## Collaborators

- JT Pyle
- Talia Olsen
- Israel Ojo
- Godwin Essien
- Clarence Ahiabor
- Dakota Paul Haithcock

## Components

- Create scripture memorizer
- Scripture memorizer database connection
- Delete memorized scripture
- Display list of scriptures to memorize
- Update a scripture to memorized extent
- Get blanked out memorized scripture to memorize
- Front end displays for the project
